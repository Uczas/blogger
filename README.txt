UGBOSU WRITING STUDIO

SETUP
Replace the index.html at blogger.ugbosu.com with the enclosed index.html.
This is your blog-writing tool, so do not replace the homepage at ugbosu.com.
The editor is contained in one HTML file; no build step is needed.

WRITE A BLOG
1. Enter a title and write or paste your article into the visual editor.
2. Use the toolbar for headings, bold text, lists, links and images.
3. Fill in the publication date and search description. The filename is
   generated from your title and can be edited.
4. Optionally add a cover image, subtitle and up to three related articles.
5. Choose Preview to inspect the article in desktop or mobile width.
6. Choose Download article and upload the resulting HTML to the blogs
   folder on ugbosu.com, using your usual publishing process.

Use Load template example to load your uploaded "From Snake to Startups"
article. Loading the example or starting a new article replaces the current
browser draft after confirmation.

DRAFTS
The latest draft saves automatically in this browser on this device.
Download draft saves an editable JSON backup. Open draft restores that file.
Keep a backup before clearing browser storage or switching devices.
This editor does not provide cloud synchronization or automatic publishing.

IMAGES AND WEBSITE ASSETS
Upload images to your website first, then enter their public image URL or
site path, such as /images/example.jpg. Cover and article images retain
full proportions without cropping.
Exported articles use the shared CSS and JavaScript paths from your uploaded
article template. Keep those assets on your main website. The shared header,
footer, compact byline and optional newsletter are included automatically.
The preview embeds a snapshot of the shared styles. Links, scripts and forms
are disabled there; check the exported article on your site before publishing.
If you later change your site's shared styles, exported articles will use
those newer styles, while this builder's preview retains its embedded snapshot.

MATH AND ADVANCED HTML
Enable mathematical equations for MathJax on the exported page. Math is not
rendered in the preview. HTML mode is optional; normal writing requires no
code. Pasted/source HTML is cleaned to retain supported article formatting
and remove scripts, forms and unsafe attributes.

VERIFICATION
Automated DOM checks passed for initialization, slugs, article text, shared
header/footer, export, metadata escaping, optional sections, MathJax syntax,
preview isolation, HTML sanitization, required fields and local draft saving.
A live visual browser check was blocked by the preview browser's local-file
security policy, so visual editing and layout still need a quick check in your
own browser after uploading.
